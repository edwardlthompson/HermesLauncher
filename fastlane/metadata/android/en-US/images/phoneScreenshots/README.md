# Phone screenshots

This folder is the F-Droid / Fastlane `phoneScreenshots` target.

No device or emulator captures are in git yet. Do not add dummy, placeholder,
or generated mock-ups — F-Droid listing checks reject those.

Capture on a phone or emulator (`[ADB]` / `[HUMAN]`):

1. Inbox (page 0) with a few notification cards
2. News or Podcasts page
3. A widget page and the app drawer

Save PNGs here (typical 16:9 or device frames), then delete this README so
the folder contains only screenshots.
